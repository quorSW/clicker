# Что от тебя требуется

## Минимум (игра работает без этого)

Можешь просто залить папку на любой хостинг и подключить к боту — игра будет работать. Тапалка, магазин, статистика, профиль с данными из Telegram.

---

## Чтобы рейтинг показывал реальных людей

Рейтинг работает только с Firebase. Без него видишь только себя.

### Шаг 1. Создай проект Firebase

1. Зайди на https://console.firebase.google.com
2. Нажми **«Создать проект»** → придумай имя → готово
3. В меню слева: **Build** → **Firestore Database** → **Create database**
4. Режим **Start in test mode** → выбери регион → **Enable**

### Шаг 2. Получи конфиг

1. Иконка шестерёнки рядом с «Project Overview» → **Project settings**
2. Прокрути вниз → **Your apps** → нажми иконку `</>`
3. Придумай имя приложения → **Register app**
4. Скопируй объект `firebaseConfig` (строки с apiKey, authDomain и т.д.)

### Шаг 3. Вставь в config.js

Открой файл **config.js** и замени `YOUR_...` на свои значения:

```javascript
const FIREBASE_CONFIG = {
  apiKey: "твой-apiKey",
  authDomain: "твой-проект.firebaseapp.com",
  projectId: "твой-projectId",
  storageBucket: "твой-проект.appspot.com",
  messagingSenderId: "твой-senderId",
  appId: "твой-appId"
};

const FIREBASE_ENABLED = true;  // ← важно!
```

### Шаг 4. Перезалей игру на хостинг

После изменения config.js заново залей файлы на хостинг.

## Подключение к боту в Telegram

1. Создай бота через [@BotFather](https://t.me/BotFather): `/newbot`
2. Залей игру на хостинг (GitHub Pages, Vercel, Netlify — бесплатно)
3. В BotFather: `/mybots` → твой бот → **Bot Settings** → **Menu Button** → **Configure**
4. Введи URL твоей игры (например: `https://твой-сайт.vercel.app`)
5. Текст кнопки: `Играть`

Готово. Открываешь бота — нажимаешь кнопку — игра открывается.
